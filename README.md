# AI Studio Club pour Claude

Pour les membres d'AI Studio Club.

1. Dans Claude : Customize, Plugins, Add marketplace.
2. Colle ce lien : `https://github.com/AISTUDIOOSS/ai-studio-club`
3. Installe AI Studio Club.
4. Dans l'onglet Connectors du plugin, connecte AI Studio Club. Ajoute ta clé fal sur ta page Studio.
5. Tape `/photoshoot-pro` dans Claude : il crée le shooting avec tes photos, le lance après ton accord, te dit où il en est et demande les retouches. Tout tourne sur le Club, même si tu fermes le chat.

Il faut un abonnement Claude payant et un compte du Club.
